# Глоссарий — слова, которые встречаются в расчёте и на экранах

Автор: Маулен (соучредитель). Один термин — одно значение, одинаково в README, на экранах и в обосновании.

| Термин | Что значит | Где видно |
|---|---|---|
| Код 1С (`code_1c`) | Ключ артикула из учётной системы партнёра, например `130300027_` | карточка артикула; в файле для 1С — колонка «Номенклатура.Код» |
| Артикул поставщика | Код товара у IEK или SE, например `U733M` | карточка, экспорт |
| Регулярный спрос | Среднее продаж в месяц по месяцам без дефицита, без разовых документов | обоснование |
| Разовый документ | Документ продажи, количество по которому выше порога артикула | «исключено разовых документов: …» |
| Порог разового документа | max(20 шт, min(3 × медиана месяца, 5 × p95 документа)) | `components.outlier_threshold` |
| Месяц дефицита (stockout) | Остаток на начало 0 или неизвестен, а в двух из трёх предыдущих месяцев были продажи | «Без продаж из-за отсутствия остатка: …» |
| Компенсация дефицита | На сколько продажи месяцев дефицита ниже регулярного спроса | `stockout_uplift` |
| Сезонный индекс | Во сколько раз месяц отличается от среднего; собственный у артикула или индекс поставщика | прогноз по месяцам |
| Рост | Последние 6 месяцев к тем же месяцам год назад, от ×0,5 до ×1,5 | обоснование «рост ×…» |
| Срок поставки (L) | Дней от заказа до прихода: IEK 40, SE 50 (политика) | параметры |
| Период пересмотра (R) | Как часто пересчитываем заказ: 30 дней | параметры |
| Горизонт | L + R — на сколько дней вперёд покрываем спрос | «прогноз на … дн» |
| Страховой запас | Запас на случай разброса спроса при уровне сервиса 90 % | «+ запас …» |
| Текущий остаток | Остаток на 22.09.2026: SE — «Свободный остаток», IEK — начало сентября минус отгрузки сентября | «− остаток …» |
| Товар в пути | Заказано и ещё не пришло | «− в пути …» |
| Кратность / MOQ | Минимальная партия или шаг заказа; количество округляется вверх до неё | «(кратность …)» |
| Срочность | «критично» — запаса меньше срока поставки; «скоро» — меньше горизонта; «планово»; «не требуется» | метка строки |
| Предложение | Подготовленное агентом решение, которое ждёт человека | очередь решений |
| Устарело — есть новая версия | Данные изменились после подготовки предложения; старую версию утвердить нельзя | состояние предложения |
| Обязательство | Деньги, которые компания должна поставщику по утверждённому заказу: 30 % при утверждении, 70 % к сроку поставки | экран «Деньги» |
| Себестоимость не задана | У позиции нет себестоимости в данных (все IEK); в суммах она не считается нулём | деньги, заказ |
| Правила без LLM | Режим без AI-ключей: расчёт детерминирован | метка режима |
| Черновик заказа — не отправлен | Заказ поставщику подготовлен, но не отправлен; отправляет человек | страница поставщика |
| Симулятор мира — синтетическое событие | Событие, которое ввёл пользователь или жюри, а не пришло из данных | лента событий |
