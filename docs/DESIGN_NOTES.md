# Заметки о дизайне — чего интерфейс сознательно не делает

Автор: Маулен (соучредитель). Каждое «не делает» — защита менеджера по закупу от ошибки, которая стоит денег.

1. **Не отправляет заказ поставщику сам.** Ни по таймеру, ни по «высокой уверенности». После утверждения — черновик письма и файл; отправляет человек. Это требование ТЗ и здравый смысл: ошибка в заказе на 50 дней вперёд не отменяется.
2. **Не затирает рекомендацию правкой менеджера.** Поправленное количество стоит рядом с рассчитанным, с причиной. Через месяц видно, кто был прав.
3. **Не показывает ноль вместо «не знаю».** Для IEK себестоимости в данных нет — пишем «себестоимость не задана», а не 0 KZT. Пустой остаток в выгрузке ≠ нулевой остаток.
4. **Не прячет исключённые продажи.** Если разовый документ выкинут из расчёта, он виден в обосновании как «исключено», и его можно вернуть.
5. **Не выдаёт симуляцию за реальность.** Событие, которое ввёл пользователь, подписано «Симулятор мира — синтетическое событие»; ответ поставщика — «Подтверждено (симулятор)»; нет значка «1С подключена».
6. **Не делает вид, что AI ответил, когда он не ответил.** Если провайдер недоступен — «Провайдер недоступен», а не придуманный ответ. Без ключей всё работает на «Правилах без LLM», и это подписано.
7. **Не утверждает устаревшее.** Если после открытия заказа пришло событие и расчёт изменился, утверждение старой версии не пройдёт — «устарело — есть новая версия».
8. **Не пересчитывает всё из-за одной поставки.** Событие затрагивает свои артикулы; остальной список не «прыгает» под руками.
9. **Не складывает разные валюты и не считает деньги дробями с плавающей точкой.** Суммы — в тенге, до тиын.
10. **Не заставляет открывать шесть файлов.** Всё, что нужно для решения по строке, — в одной карточке артикула.
11. **Не прячет главное за графиками.** Первым идёт вопрос «что нужно от меня», затем деньги, затем история.
