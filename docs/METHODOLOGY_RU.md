# Методика расчёта заказа — формулы и один разобранный артикул

Автор: Маулен (соучредитель). Как считается рекомендуемый заказ, простыми словами и формулами, и один артикул SE, пересчитанный по шагам. Код — `src/domain/engine.ts` (`computeNeed`); если код и этот текст разойдутся, прав код, а текст надо поправить.

## Формулы

Обозначения: L — срок поставки (IEK 40 дн, SE 50 дн), R — период пересмотра (30 дн), H = L + R — горизонт.

1. **Регулярный спрос в месяц** = среднее продаж по месяцам без дефицита, после исключения разовых документов.
2. **Разовый документ**: количество по документу за месяц > max(20 шт, min(3 × медиана месячных продаж, 5 × p95 количества в документе)); p95 считается по остальным документам артикула, без проверяемого (при менее чем шести документах — их медиана).
3. **Месяц дефицита**: остаток на начало 0 или неизвестен, а в двух из трёх предыдущих месяцев были продажи (отрицательный известный остаток — не дефицит). Такой месяц не тянет среднее вниз.
4. **Сезонный индекс месяца**: собственный (среднее продаж этого календарного месяца / регулярный спрос), если у артикула ≥ 12 месяцев с продажами без дефицита; иначе индекс поставщика.
5. **Рост** = продажи последних 6 месяцев / те же 6 месяцев год назад, в пределах 0,5…1,5.
6. **Прогноз на горизонт** = Σ по дням горизонта (регулярный спрос × рост × индекс месяца / 30).
7. **Страховой запас** = z × σ / √30 × √L; z = 1,28 при уровне сервиса 90 %; σ — разброс месячных продаж.
8. **Потребность** = max(0, прогноз + страховой запас − текущий остаток − товар в пути − утверждённые, но ещё не полученные заказы), округлённая вверх: у SE — до кратности, у IEK — не меньше минимальной партии. Текущий остаток — на 22.09.2026: у SE «Свободный остаток» из файла товара в пути, у IEK остаток на начало сентября минус отгрузки сентября.
9. **Срочность**: дней покрытия = (остаток + в пути) / (регулярный спрос × рост / 30); меньше L — «критично», меньше H — «скоро», иначе «планово».

## Разбор: розетка 2-я IP54 Alas Profi 54 белая (`300200745_`, SE)

Расчёт приложения (`POST /api/calc/run`, поставщик SE) на данных партнёра, 23.09.2026, код `main` @ `9b01fcb`. Обоснование строки дословно: «фактические продажи 75.906 шт/мес; спрос с учётом дефицита 75.906 шт/мес; сезонность артикула, рост ×0.789; прогноз на 80 дн 193.023 + запас 73.33 − остаток 23 − в пути 120 − утверждённый заказ 0 шт = потребность 126 шт (кратность 6 шт). Ожидаемые поставки: 120 шт прибудет до 11.11».

| Шаг | Значение |
|---|---|
| Порог разового документа | max(20, min(3 × 77, 5 × 60)) = **231 шт**; исключённых документов нет |
| Месяцев дефицита | нет |
| Регулярный спрос | **75,906 шт/мес** (фактические продажи = спрос с учётом дефицита: месяцев дефицита нет) |
| Сезонность | собственная (у артикула больше 12 месяцев с продажами) |
| Рост | **×0,789** (последние 6 месяцев ниже прошлогодних) |
| Горизонт | 50 + 30 = **80 дней** |
| Прогноз на 80 дней | **193,023 шт** |
| Страховой запас | **73,33 шт** |
| Текущий остаток на 22.09.2026 («Свободный остаток») | **23 шт** |
| В пути от SE | **120 шт** |
| Потребность до округления | 193,023 + 73,33 − 23 − 120 − 0 (утверждённых заказов нет) = **123,353 шт** |
| Кратность | 6 → **126 шт** |
| Дней покрытия / срочность | (23 + 120) / (75,906 × 0,789 / 30) ≈ 72 дня: больше 50, меньше 80 → **«скоро»** |
| Сумма по себестоимости | 126 × 3 072,64 = **387 152,64 KZT** |

**Проверка пункта 1 ТЗ на этом артикуле.** Без 120 шт в пути потребность до округления была бы 243,353 → 246 шт. И обратно: если в ленту приходит «Товар в пути +100» по этому коду, агент пересчитывает только его, и рекомендация становится **24 шт** («− в пути 220»). Это проверено в приложении.

**Почему важен текущий остаток.** В помесячном отчёте остаток на начало сентября — 181 шт; к 22.09 свободно 23 шт. Если считать от начала месяца, заказ был бы на 158 шт меньше, и позиция выглядела бы спокойнее, чем есть.

## Ограничения методики (честно)

- Сезонный индекс по собственной истории артикула за 2–3 года шумный: один крупный месяц сильно двигает индекс. Для редких позиций надёжнее индекс поставщика.
- Возвраты (отрицательные строки) уменьшают месяц; на редких позициях индекс месяца может уйти в минус.
- Порог разового документа берёт *меньший* из двух ориентиров. У ходовой позиции ВА47-29 25А (`010500008_`: медиана месяца 14 502 шт, обычный документ до 144 шт) порог 720 шт, и из расчёта исключены 14 документов от 807 до 7 488 шт; регулярный спрос — 13 193 шт/мес. Это видно в обосновании списком номеров, и менеджер может вернуть документ в расчёт, если это обычный оптовый клиент.
