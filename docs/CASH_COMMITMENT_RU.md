# Что утверждённый заказ делает с деньгами — записка финансиста

Автор: Маулен (соучредитель). Закупка — это обязательство по деньгам раньше, чем товар придёт. Ниже — как это считает сервис и как читать экран «Деньги».

## Правило

- Условия оплаты поставщику (политика команды, редактируема): **30 % предоплата при утверждении, 70 % — к сроку поставки** (IEK 40 дней, SE 50 дней).
- При утверждении заказа создаются два обязательства: `supplier_prepayment` и `supplier_balance`. Повторное утверждение того же заказа второй пары не создаёт.
- Сумма = Σ количество × себестоимость («СС реал», только SE). Строки без себестоимости (IEK) в сумму не входят и считаются отдельно: «себестоимость не задана».
- Деньги считаются в тенге до тиын; валюты не складываются.

## Пример на данных партнёра (23.09.2026)

Расчёт по SE дал предложение «Заказ поставщику SE: 307 позиций». После утверждения предложения и заказа:
- заказ — 70 933 шт на **70 810 601,71 KZT** по себестоимости; себестоимость известна для 271 из 307 строк, 36 строк — «себестоимость не задана» и в сумму не входят;
- предоплата 30 % — **21 243 180,51 KZT** сразу;
- остаток 70 % — **49 567 421,20 KZT** к 12.11.2026 (срок поставки SE — 50 дней).

Для финансового директора это главный вопрос дня: 21 млн тенге уходят сегодня, ещё почти 50 млн — через семь недель. Если это много, менеджер уменьшает заказ по позициям «планово» и оставляет «критично».

## Как читать экран «Деньги»

1. **Заморожено по поставщикам** — сумма утверждённых заказов по SE; по IEK — число строк без себестоимости.
2. **Платежи на 60 дней** — даты и суммы предоплат и остатков.
3. **Стоимость запаса** — только по позициям с известной себестоимостью (у IEK её нет совсем), поэтому стоимость запаса — нижняя оценка.

## Что спросит финансовый директор

- *Можем ли мы позволить заказ?* Сравнить предоплату с деньгами на счёте сегодня и платежами ближайших 60 дней.
- *Где лишние деньги в запасе?* Позиции с покрытием больше горизонта и рекомендацией 0 — кандидаты на паузу закупки (пример — розетка BLANCA в `docs/FINANCIAL_EXAMPLE.md`).
- *Чего не хватает в данных?* Себестоимости IEK. Без неё деньги по IEK не посчитать честно; это первый запрос к партнёру.
