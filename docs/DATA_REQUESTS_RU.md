# Что попросить у партнёра, чтобы расчёт стал точнее

Автор: Маулен (соучредитель). Список по приоритету. Всё — обезличенные выгрузки из 1С в том же виде, что уже получены.

1. **Себестоимость IEK** (аналог «СС реал» у SE). Без неё по IEK не посчитать ни сумму заказа, ни деньги в запасе: сейчас это 3 185 артикулов с «себестоимость не задана».
2. **Фактические сроки поставки** по поставщикам (дата заказа → дата прихода за последний год). Сейчас это допущение: IEK 40 дней, SE 50 дней.
3. **Даты прихода товара в пути.** В файлах есть количество, но нет даты; сейчас дата = 22.09.2026 + срок поставки.
4. **Условия оплаты** поставщикам (предоплата, отсрочка). Сейчас допущение 30 % / 70 %.
5. **Обезличенный идентификатор клиента** в строках продаж (хэш, не имя). Он нужен, чтобы отличать «разовую покупку одного клиента» от «регулярного оптовика» — сейчас это различается только по размеру документа.
6. **Ежедневные остатки** или хотя бы остаток на дату выгрузки по IEK (как «Свободный остаток» у SE). Сейчас для IEK текущий остаток = остаток на начало сентября минус отгрузки сентября.
7. **Отметка о выводе позиции из ассортимента.** Чтобы не рекомендовать заказ по позициям, которые партнёр больше не закупает.

Почему именно эти: пункты 1–4 превращают допущения в данные; пункты 5–7 уменьшают число ручных правок менеджера.
