# Документы закупки

Слой документов принимает фото, PDF, XLSX, CSV и TXT до 10 МБ. Таблицы разбираются локально; фото и PDF распознаются моделью при доступном ключе и лимите. Если распознавание недоступно, файл сохраняется для проверки, а API сообщает об этом прямо. По коду 1С, артикулу и названию строки сопоставляются с заказом; после загрузки акта приёмки сопоставление становится трёхсторонним. Расхождения по количеству и цене видны по строкам. Для договора и других документов с типом `other` загрузка принимает `package_key`, например `contract` или `conformity`.

Маршрут хранится у поставщика: `domestic`, `eaeu`, `import`. Для IEK и Systeme Electric пока принят маршрут ЕАЭС по умолчанию; его нужно уточнить у менеджера. `PATCH /api/suppliers/:id` с телом `{"route":"eaeu"}` фиксирует маршрут.

| Маршрут | Пакет |
| --- | --- |
| Внутри РК | Счёт на оплату, договор, ЭСФ, накладная на отпуск запасов, акт приёмки |
| ЕАЭС | Договор, счёт/инвойс, УПД/ТОРГ-12, CMR/ТТН, форма 328.00, НДС при импорте 12 % (форма 320.00), статистическая форма, сертификат/декларация соответствия ЕАЭС, акт приёмки |
| Третьи страны | Контракт, инвойс, packing list, транспортный документ, сертификат происхождения, предложения кодов ТН ВЭД ЕАЭС, Пакет для проверки и передачи таможенному представителю (оформление в «Кеден»), пошлина/НДС 12 %/сбор, сертификаты соответствия, акт приёмки |

Для ввоза из ЕАЭС ДТ не требуется. Пакет показывает `present`, `missing`, `draft` или `discrepancy` для каждого пункта и состояние каждого этапа. Форма 328.00 и проект ДТ — **«Черновик подготовлен агентом — не отправлен»**. Предложение ТН ВЭД содержит только товарную позицию из 4 знаков, если название позволяет её предложить; полный код и классификацию проверяет декларант. Подключения к «Кеден», ЭСФ и 1С нет; ничего никуда не отправляется.

## Проверка за минуту

После `npm run demo:reset` запустите `npm run dev -- --webpack -p 3000`. В другом терминале:

```sh
curl -sS -X POST http://localhost:3000/api/documents -H 'Content-Type: application/json' -d '{"fixture":"iek_invoice_demo.xlsx"}' | jq '{id:.document.id,po_id:.document.po_id,mode:.document.extraction_mode,state:.document.state}'
curl -sS 'http://localhost:3000/api/documents?po_id=PO-DEMO-IEK-DOCUMENTS' | jq '.documents[0].match | {summary,lines:[.lines[]|select(.status!="ok")]}'
curl -sS http://localhost:3000/api/orders/PO-DEMO-IEK-DOCUMENTS/package | jq '{route,route_note_ru,items,stage_rail,drafts}'
```

Синтетический счёт содержит 10 реальных кодов каталога IEK и два намеренных расхождения: количество 60 против 100 и цену во второй строке. Растровый вариант `iek_invoice_demo_photo.png` проходит через `replay.json` без ключа модели. Цены и количества демонстрационные; происхождение описано в `fixtures/PROVENANCE.md`.

Мы не заменяем государственные системы - мы готовим для них согласованные данные. Загрузка документа не является подачей декларации.
