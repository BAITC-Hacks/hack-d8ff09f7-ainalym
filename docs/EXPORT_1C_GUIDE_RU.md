# Файл заказа для 1С — что в нём и как им пользоваться

Автор: Маулен (соучредитель). Сервис не подключается к 1С партнёра и ничего в неё не пишет. После утверждения заказа он отдаёт файл, который бухгалтер или закупщик загружает штатными средствами. Ключ строки — код 1С («Номенклатура.Код»), тот же, что в выгрузках партнёра.

## Где взять файл

- В интерфейсе: заказ `/orders/:id` → экспорт.
- Через API: `GET /api/orders/:id/export.xlsx` или `GET /api/orders/:id/export.csv`.
- Файл формируется только по утверждённому заказу; черновик поставщику при этом не отправляется.

## Колонки

Файл называется «Заказ_поставщику_<SE|IEK>_<дата>.xlsx» и повторяет табличную часть документа 1С «Заказ поставщику».

| Колонка | Что в ней | Откуда |
|---|---|---|
| Номенклатура.Код | код 1С, например `300200745_` | выгрузки партнёра |
| Номенклатура | наименование, как в 1С | выгрузки партнёра |
| Артикул | код у поставщика, например `ATN540126` | файл товара в пути SE, MOQ IEK |
| Ед. | единица измерения | выгрузки партнёра |
| Количество | утверждённое количество (правка менеджера, если была, иначе рекомендация) | расчёт |
| Цена | себестоимость («СС реал», только SE); у IEK пусто | выгрузка SE |
| Поставщик | IEK или SE | справочник поставщиков |
| Дата поставки | ожидаемая дата прихода по сроку поставки | политика сроков |
| Срочность | критично / скоро / планово | расчёт |
| Обоснование | одна строка с числами: спрос, сезонность, рост, прогноз, запас, остаток, в пути | расчёт |

Проверено на данных партнёра 23.09.2026: утверждённый заказ SE дал файл «Заказ_поставщику_SE_2026-09-23.xlsx» на 317 строк; срочность — критично 69, скоро 104, планово 144.

## Как загрузить

1. Открыть файл и проверить: количество кратно «Кратности», коды 1С без пробелов (в кодах партнёра есть подчёркивание в конце, например `130300027_`, — его нельзя терять).
2. В 1С создать «Заказ поставщику» и заполнить табличную часть загрузкой из файла по колонке «Номенклатура.Код» (обработка загрузки из табличного документа, сопоставление по коду).
3. Колонку «Обоснование» перенести в комментарий строки — через месяц будет видно, почему заказали столько.

## Чего файл не делает

- Не содержит цен продажи и данных клиентов.
- Не отправляет заказ поставщику: письмо остаётся черновиком «Черновик заказа — не отправлен».
- Не содержит сумм по IEK: себестоимости IEK нет в данных.
