# Вопросы менеджера по закупу — короткие ответы

Автор: Маулен (соучредитель). Вопросы, которые задаст закупщик в первый день работы с сервисом.

**Почему рекомендация больше, чем я заказал бы сам?**
Обычно по трём причинам: (1) текущий остаток на 22.09 меньше, чем остаток на начало месяца, — сентябрь уже продан; (2) в прошлом были месяцы без товара, и сервис не считает их «низким спросом»; (3) впереди сезонный месяц. Все три видны в обосновании строки числами.

**Почему рекомендация меньше?**
Исключены разовые документы (номера — в обосновании), учтён товар в пути, рост за полгода ниже прошлогоднего. Если исключённый документ на самом деле регулярный клиент — верните его в расчёт (см. `docs/OUTLIER_REVIEW_GUIDE_RU.md`).

**Можно поменять количество?**
Да. Правка сохраняется рядом с расчётом, с вашей причиной; исходная рекомендация не затирается.

**Сервис сам отправит заказ поставщику?**
Нет. После утверждения готовятся черновик письма и файл для 1С. Отправляет человек. На странице поставщика это подписано «Черновик заказа — не отправлен».

**Как загрузить файл в 1С?**
Экспорт — файл «Заказ_поставщику_<SE|IEK>_<дата>.xlsx» в форме документа 1С «Заказ поставщику»: «Номенклатура.Код», «Номенклатура», «Артикул», «Ед.», «Количество», «Цена», «Поставщик», «Дата поставки (ETA)», «Срочность», «Обоснование». Прямого подключения к 1С нет: файл загружается штатной обработкой.

**Почему у IEK нет суммы заказа?**
В выгрузке IEK нет себестоимости. Сервис показывает «себестоимость не задана» и число таких строк, а не 0 KZT.

**Что будет, если пришла поставка или новый день продаж?**
Событие попадает в ленту, агент пересчитывает только затронутые артикулы. Если предложение по ним ещё не утверждено, оно становится «устарело — есть новая версия».

**Откуда сроки поставки 40 и 50 дней?**
Это политика команды, не данные партнёра. Их можно поменять — изменение проходит как предложение и запускает пересчёт.

**Работает без интернета и AI?**
Да: режим «Правила без LLM». Расчёт M1–M5 детерминирован; AI нужен только для пограничных документов, черновиков писем и голоса.
