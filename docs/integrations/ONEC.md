# 1С УТ: файловый вход и выход

## Что приходит

- Партнёр передал двенадцать обезличенных стандартных XLSX-отчётов 1С УТ для IEK и SE; реестр и поля — в `fixtures/PROVENANCE.md`.
- `npm run etl` загружает динамику продаж, ежемесячные продажи и остатки, товар в пути, MOQ и сезонность без доработки конфигурации 1С. `GET /api/modes` показывает файловый вход `onec_in` и время последней ETL-загрузки из `organization.payload.etl_fetched_at`.

## Что выходит

- После утверждения «Заказа поставщику» API отдаёт CSV или XLSX «Экспорт для 1С (файл)» с кодом 1С, номенклатурой, артикулом, единицей, количеством, известной ценой, поставщиком, ETA, срочностью и обоснованием.
- Имя скачиваемого файла: `Заказ_поставщику_<SE|IEK>_<YYYY-MM-DD>.xlsx|csv`. Формат колонок зафиксирован в `docs/CONTRACTS.md`.

## Что не подключено

- Нет автоматической записи в учётную систему, живого OData или EnterpriseData-коннектора. Загрузка экспортного файла в 1С выполняется отдельно.
- Диагностика тестовой базы 1С раскрыта в README §10; она не подтверждает действующее бизнес-подключение.
