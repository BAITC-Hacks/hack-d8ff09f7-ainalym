# ASSIST-1 — «ИИ-ассистент» dock (Fable v2 shell) — closeout

- **Built:** `AssistantDock` (`src/components/assistant/AssistantDock.tsx` + `dock.module.css`) — a Linear-style side sheet (440 px, fixed right, no page shift) on the v2 tokens; opens from the sidebar item «ИИ-ассистент» (portalled into the shell nav, `Shell.tsx` untouched) or ⌘J / Ctrl+J, closes on Esc; chips per page, text composer, answers as `ResultCard` (plain mode, links rebased onto the shell prefix); «Открыть отдельно» opens the same conversation as a 480×760 popup (`/v2/assistant?ctx=…`, page mode, sidebar + top bar hidden); the conversation is shared both ways via localStorage (12 h TTL) + `storage` sync.
- **Page context:** `src/components/assistant/context.ts` reads route + entity from the pathname (`/today`, `/replenishment`, `/skus/[code]`, `/orders[/id]`, `/suppliers[/id]`, `/supplier/[po]`, `/money`, `/world`; unknown → generic prompts; `/v2`, `/opus_a` or `/` prefix auto-detected) and merges an optional `data-ainalym-context` JSON attribute published by `PageContext` (mounted on the v2 money and SKU pages). Each message posts `{ text, context, base }` to `POST /api/assistant/ask`.
- **Keyless answers:** `src/server/assistant_answers.ts` answers every suggested prompt from saved data (recommendation components/rationale, orders, cash-flow view, queue, ledger): «Что заплатить на этой неделе?», «Почему заказ такой?», «Что срочно?», «Почему столько?», «Что изменится, если +N в пути?», «Что нужно от меня?», «Что изменилось?». No AI key, no new write endpoints; actions are links to existing screens. Unknown text → «Не могу ответить по этим данным. Попробуйте открыть карточку товара.»
- **Language audit:** `ResultCard` no longer shows the data-version line, hides truth chips in plain mode, marks failed answers with an alert icon; `AssistantPanel` footer no longer says “Realtime + async speech” / “Provider unavailable”. The API never returns error codes or technical words to the UI — always plain Russian (regex-tested).
- **Mount (one line, any shell):** `<AssistantDock />` next to the shell inside the `.v2` root (already in `src/app/(v2)/layout.tsx`); pass `base=""` explicitly once the shell is served at `/`, or leave it to auto-detect. Page mode: `src/app/(v2)/v2/assistant/page.tsx` (`<AssistantDock mode="page" />`) — moves with the shell to `/assistant`.
- **Tests:** vitest `tests/ui/assistant_context.test.ts` (5) + `tests/ai/assistant_answers.test.ts` (6, keyless answers for every prompt on every page, no-tech-terms regex) — 11/11 green; Playwright `tests/e2e/assist.spec.ts` (`--config tests/e2e/assist.config.ts`, `ASSIST_URL`): /v2/money → ⌘J → chip → answer card → «Открыть отдельно» opens `/v2/assistant?ctx=` page mode → Esc closes; /v2/skus/130300027_ → both chips answer with links — 2/2 green.
