# Текст для «Сдать решение» — v1 (2026-09-23 08:45Z)

**Название:** Айналым — автоматический расчёт заказов поставщикам для пополнения склада

**Описание:** Айналым — финансовая операционная система для торгового бизнеса. Агенты ведут коммерческий цикл. Вы принимаете решения. Первая вертикаль — кейс ТОО «Электрокомплект»: по истории продаж, сезонности, росту спроса, остаткам, товару в пути и категориям сервис считает рекомендуемый заказ по каждому артикулу, исключает разовые крупные заказы, компенсирует спрос, упущенный в периоды отсутствия товара, и собирает список заказов по поставщикам IEK и System Electric с обоснованием по каждой строке. Менеджер по закупу корректирует и утверждает; автоматической отправки поставщику нет; экспорт — файл, совместимый с 1С по колонке «Код 1с». Данные — обезличенные выгрузки партнёра. Методика, алгоритм исключения выбросов и запуск — в README; фактический статус каждой возможности — `docs/TASK_MAP.md`.

**Репозиторий:** https://github.com/BAITC-Hacks/hack-d8ff09f7-ainalym

**Демо-доступ:** URL и код передаются через форму платформы. Без ключей приложение запускается локально в режиме «Правила без LLM» (README, раздел 7).
