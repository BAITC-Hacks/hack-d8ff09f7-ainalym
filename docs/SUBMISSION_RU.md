# Текст для «Сдать решение» — v2 (2026-09-23 11:1xZ; синхронизировано с текстом формы платформы, которую заполняет владелец; демо-URL и код доступа только в форме, в репозитории не хранятся)

**Название:** Ainalym — автоматический расчёт заказов поставщикам для пополнения склада

**Теги:** next.js, typescript, sqlite, forecasting, replenishment, ai-agents, explainable-ai, 1c-export, voice-assistant, hosted-demo

**Описание:**

Ainalym считает, сколько и у кого заказать, чтобы склад не пустел и не переполнялся. По данным ТОО «Электрокомплект» сервис учитывает продажи, сезонность, рост, остатки и товар в пути, убирает разовые крупные заказы и собирает заказы поставщикам IEK и Systeme Electric с обоснованием каждой строки.

Проблема. Менеджер по закупу вручную сводит продажи, остатки и поставки по тысячам артикулов. Ошибка стоит либо пустых полок, либо замороженных денег.

Что сделано. Загружены все 12 выгрузок партнёра: 3 909 артикулов, 249 тыс. строк продаж за 2023–2026, остатки и продажи по месяцам, минимальные партии и кратность, товар в пути с датами прихода. Движок по каждому артикулу: базовый спрос по всем источникам → сезонный индекс и устойчивый рост → компенсация спроса, упущенного в месяцы без товара → прогноз на срок поставки и страховой запас → минус остаток, товар в пути и уже утверждённые заказы → округление под правила поставщика (минимум IEK, кратность Systeme Electric). Результат группируется по поставщикам и выгружается в Excel/CSV со столбцом «Код 1с».

Выбросы. Разовый крупный документ исключается по порогу от медианы и 95-го перцентиля продаж по документам, рассчитанному без самого проверяемого документа, поэтому искусственно добавленный заказ не сдвигает собственный порог. Проверка встроена: инъекция события → пересчёт → изменение потребности 0 %.

Объяснимость и контроль. Каждая строка показывает, из чего сложилась цифра: спрос, сезон, рост, упущенные продажи, остаток, в пути, правило округления. Менеджер правит количество с указанием причины и утверждает. Автоматической отправки поставщику нет. Ответ поставщика («отгрузим 60 %, остальное через три недели») превращается в предложение разбить или ускорить заказ.

Как проверить. Демо: URL и код доступа передаются через форму платформы. Личные аккаунты не нужны. Локально без ключей работает режим «Правила без LLM»; методика, алгоритм выбросов, запуск и сводная проверка (235 автотестов) описаны в README.

Технологии. Next.js, TypeScript, SQLite; ИИ-слой с типизированными решениями (OpenAI, Jev, правила) и журналом действий агентов; голосовой помощник в экспериментальном режиме.

Расчёт заказов — первый модуль Ainalym, операционной системы для торгового бизнеса: агенты ведут коммерческий цикл, решения принимает человек.
