# Текст для «Сдать решение» — v2 (2026-09-23 11:15Z)

**Название:** Ainalym — автоматический расчёт заказов поставщикам для пополнения склада

**Описание:** Ainalym — финансовая операционная система для торгового бизнеса. Агенты ведут коммерческий цикл. Вы принимаете решения. Первая вертикаль — кейс ТОО «Электрокомплект»: по истории продаж, сезонности, росту спроса, текущим остаткам, товару в пути и категориям сервис рассчитывает рекомендуемый заказ по каждому товару, не учитывает разовые крупные продажи в регулярном спросе, восполняет спрос, упущенный, когда товара не было на складе, и собирает список заказов по поставщикам IEK и System Electric с объяснением каждой цифры. Менеджер по закупу правит количество и утверждает заказ; сам сервис поставщику ничего не отправляет — он готовит черновик письма и файл «Заказ поставщику» для загрузки в 1С. Сразу видно, сколько денег заказ замораживает и когда платить. Все пять обязательных проверок кейса проходят на обезличенных данных партнёра; как их повторить — в README.
