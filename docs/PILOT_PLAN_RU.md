# План пилота с партнёром — что и как измерить

Автор: Маулен (соучредитель). Здесь нет обещанной экономии: её ещё никто не измерял. Здесь — как её измерить честно за 8–12 недель.

## Что сравниваем

Две группы артикулов одного поставщика (например, SE, категории «Категория 2026»):
- **группа А** — заказывает менеджер как сейчас;
- **группа Б** — менеджер утверждает рекомендации сервиса (с правками и причинами).

Группы подбираются похожими по обороту и сезонности. Партнёр решает, какой поставщик и какие категории.

## Метрики (из тех же выгрузок 1С, без новых систем)

| Метрика | Как считаем | Откуда данные |
|---|---|---|
| Месяцы дефицита | число месяцев с нулевым/неизвестным остатком на начало после продаж | помесячные остатки и продажи |
| Упущенные продажи (оценка) | регулярный спрос × дни без товара | расчёт сервиса |
| Деньги в запасе сверх горизонта | (остаток − потребность на L + R) × себестоимость | остатки, «СС реал» |
| Время менеджера на расчёт | минуты на один расчёт по поставщику | самоотчёт менеджера |
| Доля правок | строк, где менеджер изменил количество / все строки | журнал утверждений |
| Причины правок | классификация причин из комментариев | журнал |

## Условия

- Данные только обезличенные, как в соревновании; клиенты не передаются.
- Себестоимость IEK — первое, что нужно для денежных метрик по IEK.
- Сроки поставки и условия оплаты — уточнить у партнёра вместо допущений 40/50 дней и 30/70 %.
- Автоматической отправки поставщику нет и в пилоте.

## Решение по итогам

Продолжаем, если в группе Б меньше месяцев дефицита и денег сверх горизонта при сопоставимом времени менеджера, а доля правок падает от недели к неделе. Если нет — разбираем причины правок: это и есть список доработок методики.
