## Три фразы, которые должны остаться у жюри

1. Каждое число объяснено, разовые заказы видны и исключены.
2. Решает человек: ничего не отправляется само.
3. Запускается из README без ключей, в режиме «Правила без LLM».

## Чего не говорим

Не называем экономию в деньгах, которой не измеряли; не говорим «интеграция с 1С» (только файл); не называем клиентов, которых нет.
