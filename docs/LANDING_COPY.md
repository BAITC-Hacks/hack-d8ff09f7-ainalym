## Главный экран (hero)

**Айналым — финансовая операционная система для торгового бизнеса.**
Агенты ведут коммерческий цикл. Вы принимаете решения.

Подзаголовок: Полный круг бизнеса — договорённости, исполнение, деньги и учёт — на одном экране.

Кнопки: «Открыть демо» · «Как проверить (README)»

Под кнопками мелко: «Айналым» по-казахски — «полный круг».

## Экран продукта

Подпись к снимку экрана: Пульс закупа: что под риском дефицита, какие решения ждут вас, сколько денег уже заморожено в заказах и что агенты сделали без вас.

## Цикл, который ведут агенты

1. **Данные.** Продажи, остатки, товар в пути, кратность и сезонность — из выгрузок 1С, без ручного ввода.
2. **Расчёт.** По каждому артикулу: без разовых заказов, с поправкой на месяцы без товара, с сезоном и ростом.
3. **Рекомендация.** Список по поставщикам, у каждой строки — почему именно столько.
4. **Решение.** Вы правите количество и утверждаете. Без вас заказ не уходит.
5. **Деньги и учёт.** Файл для 1С, черновик письма поставщику, платежи по датам.

## Что работает сегодня — честно

- Данные: реальные обезличенные выгрузки дистрибьютора электротехники (ТОО «Электрокомплект»), два поставщика.
- Расчёт работает и без AI-ключей — в режиме «Правила без LLM».
- 1С: только файл, совместимый по колонке «Код 1с»; прямого подключения нет.
- Поставщик: письмо — черновик, не отправляется; ответ поставщика в демо — симулятор, и это подписано на экране.

## Вход в демо

Адрес и код доступа выдаются организаторам через платформу. Локально — `npm install`, `npm run dev`, без ключей.
