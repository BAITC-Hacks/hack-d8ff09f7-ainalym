# DISCLOSURE — раскрытие материалов / disclosure of materials

> **Раскрытие материалов (п. 5.4.4, 5.4.4.2 Положения от 22.09.2026).** До старта соревновательной части команда подготовила: исследование предметной области и правил, продуктовые и технические заметки (Markdown), инструкции для AI-агентов, решения по стеку и черновик контракта данных и API (`docs/CONTRACTS.md`), а также дизайн-референсы (шкала типографики, отступы, цвета). Каркас приложения сгенерирован командой `create-next-app` в начале соревновательной части. **Весь код приложения, схема данных, расчётный движок, тесты и интерфейс создаются в этом репозитории во время соревновательной части.** Данные кейса (`fixtures/partner/`) — обезличенные выгрузки партнёра ТОО «Электрокомплект» (история продаж, ежемесячные остатки и продажи, MOQ, товар в пути на 22.09.2026, сезонность), предоставленные организатором для кейса; они не содержат данных о клиентах (только номера документов) и не изменяются командой. Ожидаемые результаты для автотестов (`tests/fixtures/eval/`) вычисляются из этих данных во время соревнования и используются только тестами. Документы соавтора (финансовый пример, описание сценария, тексты README) подготовлены с помощью AI-инструментов и проверены им перед фиксацией. Используемые AI-инструменты: Claude (Fable/Opus), OpenAI Codex, TypeSafe Jev (напрямую и через Vercel AI Gateway), OpenAI API (черновики, голос). Сторонние компоненты перечислены в `package.json`; шрифт Inter (SIL OFL) включён в `public/fonts`. Учётная система партнёра (1С) не подключается: экспорт формируется в виде файла, совместимого по колонкам («Код 1с»).

> **Disclosure (rules 5.4.4 and 5.4.4.2 of the 22.09.2026 regulation).** Pre-event: domain and rules research, product and technical notes, agent instructions, stack decisions, a draft data/API contract (`docs/CONTRACTS.md`) and design references (type scale, spacing, colours). The app skeleton was generated with `create-next-app` at the start of the competition window. **All application code, schema, the calculation engine, tests and UI are created in this repository during the competition window.** Case data (`fixtures/partner/`) are the anonymised exports of the partner Elektrokomplekt LLP (sales history, monthly stock and sales, MOQ, goods in transit as of 22.09.2026, seasonality) provided by the organizer for the case; they contain no customer data (document numbers only) and are not modified by the team. Expected outcomes for automated tests (`tests/fixtures/eval/`) are computed from these data during the event and used by tests only. The co-founder's documents were drafted with AI tools and reviewed by him before commit. AI tools: Claude, OpenAI Codex, TypeSafe Jev (direct and via Vercel AI Gateway), OpenAI API (drafts, voice). Third-party components: see `package.json`; the Inter font (SIL OFL) is bundled in `public/fonts`. The partner's accounting system (1C) is not connected: the export is a file compatible by columns («Код 1с»).
