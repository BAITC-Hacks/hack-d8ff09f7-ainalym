# Inter Variable

`InterVariable.woff2` is the unmodified Inter variable font from https://rsms.me/inter/font-files/InterVariable.woff2, downloaded 2026-09-23 directly from the author, not from Dain. Copyright Rasmus Andersson. SIL Open Font License 1.1: [OFL.txt](OFL.txt). Source: https://github.com/rsms/inter.

Bundled locally for `next/font/local`; builds do not download fonts. System CJK fallbacks cover source text. Only weights 400, 500 and 600 are used by the Ainalym tokens.
